Multimodal Agent Examples

This page demonstrates how to use agents that can process both text and images, audio, or other media types.

Agent Configuration

🖼️ Image Analysis with Text

Example Prompts:

  • "Describe what you see in this image"
  • "What emotions are expressed in this photo?"
  • "Extract all text from this image"
  • "Identify any objects or landmarks in this image"
  • "What's the mood or atmosphere of this scene?"

📁 Click to upload an image or drag and drop

Supports: JPG, PNG, GIF, WebP (max 10MB)

🎵 Audio Analysis

Example Use Cases:

  • Transcribe speech to text
  • Identify music genre or instruments
  • Analyze sentiment in speech
  • Extract key information from audio recordings

🎵 Click to upload an audio file

Supports: MP3, WAV, M4A, FLAC (max 25MB)

📄 Document Analysis

Example Tasks:

  • Extract information from PDFs
  • Summarize document content
  • Answer questions about documents
  • Compare multiple documents

📄 Click to upload a document

Supports: PDF, DOC, DOCX, TXT (max 50MB)

🔄 Multi-file Comparison

Example Tasks:

  • Compare two images side by side
  • Analyze changes between document versions
  • Find similarities in multiple files
  • Cross-reference information across files
